# Original experiment adapter

`ExperimentAdapter.to_state(doc)` converts a `LegacyFormats` experiment dictionary into the `LabModel.from_state` schema. `from_state(doc,state)` applies current placement, temperature, quantities, reaction-rate edits, and eligible connectors back to retained original records. It returns an `error` dictionary when new apparatus or connectors have no legacy record; callers should preserve the current experiment in the native Godot JSON format in that case. New reagent mass is obtained from the recovered reagent catalog when available.

Runtime IDs are unique sequential IDs; original repeated object-kind IDs remain in the source document. Connectors reference object names; the adapter resolves connectors joined to other connectors and deduplicates directed vessel pairs. Gas transfer uses the new engine's documented default rate of 0.2 per second, not a recovered rate. Original connector geometry and metadata remain available for rendering/export.

Equipment mapping comes from native published toolbar handlers and `TSUB_VESSEL_FORM.dfm` panel ownership: 101 is test tube; 102 beaker; 103 conical flask; 107 gas jar. For example submenu buttons 1–3 assign 102 with sizes 100/200/500, buttons 6–7 assign 103 with sizes 100/250, buttons 11–13 assign 101 with angles 0/45/97, and buttons 22–23 assign 107 with ±100. Main toolbar entry points directly establish 104/105 round/flat flasks, 106 glass tube, 108 U-tube, 207/208 burets, 209–211 funnels, 212 trough, 301 stand, 302 lamp, 303 thermometer, 316 wood and 318 image.

The original smart-reaction checkbox reads global `DAT_0059625c`, written to vessel word 0x29 (offset 0xa4) in the property apply handler (`main/decompiled.cpp`, lines 50642 and 50761); the file reader maps that offset to metadata field 36. Ion consideration and dissolution are separately persisted in simulation fields 0 and 1. Other unknown flags remain preserved. Full stored reaction definitions are now consumed by the engine through `reaction_overrides`. The adapter does not infer heating, burning, illumination or electrolysis from example titles or nearby apparatus.

Manual reactions use recorded `方程式` names, not repeated pointer-like record identifiers. Per-vessel rates are keyed by these names; `reaction_overrides` additionally carries recorded stoichiometry and all five legacy reaction parameters for the engine to consume. Renderer-facing volume is at least 1 ml so non-container decorative objects pass the new engine's validation, while original zero capacity is retained and unchanged on export.

Trailer decoding follows the native reader: custom variable count and seven-line records, chart count and fixed 55-line chart records, then annotation count and 16-line style/geometry records followed by text lines. All 204 original annotations are exposed in document `annotations` and state `annotations`/`decorators`. The source trailer remains intact for export. Binding definitions expose recovered reagent variable names; saved zero values do not overwrite simulated quantities.

`godot/tests/test_adapter.gd` loads all 28 experiments into `LabModel`, verifies unique IDs and connector endpoints, checks exact unchanged original UTF-8 round trips, and confirms position edits. These checks passed in Godot 4.7.1.

Numeric `state.variables` starts from the original custom-variable values. `state.bindings` is an array of `{name,vessel_id,species,metric}` where metric is `moles` or `mass`; the initial bound values are refreshed from actual recovered contents. `state.program` contains the exact original code lines concatenated from program groups; `program_groups` retains group metadata. For example the original titration program includes `ph1=-log10(1000.0*b1/a1)`.

Charts expose the original five fixed series slots, including each stored X/Y variable name and color. Active series omit the original placeholder pair `数值0`. Their original position is recovered; the new display size of 360×180 is explicitly marked as a port default. Original charts also appear as interactive `kind: chart` objects in state vessels, with a separate `legacy_chart_index`. Export updates original chart positions and variable names without treating charts as chemical vessels.

The project includes all 133 original byte fixtures under `godot/tests/fixtures`, referenced through catalog `fixture` paths. The encoding tests need only the Godot project, with no external recovered-source tree. Release presets should exclude tests and fixtures.
